# SiGame Pack Editor

Локальный редактор пакетов **SIGame SIQ v5**. Открывайте, редактируйте, объединяйте и проверяйте игровые паки прямо в браузере — без установки отдельной программы.

## Возможности

- **Работа с SIQ v5:** открыть существующий пакет или создать новый.
- **Редактирование структуры:** раунды, темы, вопросы, ответы и связанные параметры.
- **Несколько пакетов одновременно:** открывайте несколько .siq во вкладках, переключайтесь между ними и переносите содержимое.
- **Объединение пакетов:** собирайте содержимое нескольких паков в один.
- **Операции со структурой:** копирование, перемещение и удаление элементов; отмена и повторение действий.
- **Содержимое архива:** просмотр файлов и папок внутри пакета, поиск, фильтрация, сортировка и предпросмотр поддерживаемых ресурсов.
- **Работа с ресурсами:** добавление, замена, переименование и удаление файлов в архиве пакета.
- **Проверки:** валидация пакета, контроль ограничений SIGame и проверка результата перед экспортом.
- **Экспорт:** сохранение результата в новый файл .siq; исходный файл автоматически не перезаписывается.
- **Проверка обновлений:** редактор проверяет публичные GitHub Releases и сообщает, когда доступна новая версия.

## Быстрый запуск

1. Откройте страницу **[последнего релиза](https://github.com/SoulEmper0r/SiGamePackEditor/releases/latest)**.
2. Скачайте архив **SiGamePackEditor-vX.Y.Z.zip**.
3. Распакуйте архив целиком в отдельную папку.
4. Откройте файл **index.html** в современном браузере.
5. Нажмите **«Открыть .siq»** или перетащите один или несколько файлов пакетов в область редактора.

Установка не требуется. Не запускайте index.html прямо внутри ZIP-архива — сначала распакуйте его.

## Как устроены обновления

Проверить обновление может любой пользователь — **аккаунт GitHub и авторизация не нужны**.

1. Запустите редактор и нажмите **«Проверить обновления»** рядом с номером версии.
2. Редактор обратится к публичному API GitHub и сравнит установленную версию с последним опубликованным релизом.
3. Если вышла новая версия, в строке состояния появится ссылка на ZIP-архив обновления (или на страницу релиза, если архив ещё не приложен).
4. Скачайте архив, распакуйте его в новую папку и откройте из неё index.html.

Редактор не устанавливает обновления автоматически и не заменяет файлы на компьютере: браузер не имеет права самостоятельно перезаписывать собственные файлы приложения. Ваши .siq-пакеты хранятся отдельно и не затрагиваются обновлением программы.

Все опубликованные версии и архивы доступны на странице **[Releases](https://github.com/SoulEmper0r/SiGamePackEditor/releases)**.

## Важно

- Редактор работает с файлами локально в браузере. Содержимое ваших .siq-пакетов не отправляется в репозиторий при открытии или редактировании.
- Экспорт создаёт отдельный файл. Оригинальный пакет остаётся без изменений.
- Для проверки обновлений требуется подключение к Интернету.
- Если редактор не может обратиться к GitHub, проверьте подключение и повторите попытку позже.
